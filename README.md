# Ambrozie Scanner Premium Mobile

Aplicație Vite + React, fără API keys și fără configurări în Vercel.

## Structură GitHub

Pune fișierele direct în rădăcina repo-ului:

```txt
/
├── App.tsx
├── index.html
├── package.json
├── vite.config.ts
└── README.md
```

## Deploy Vercel

- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install

Nu sunt necesare Environment Variables.
